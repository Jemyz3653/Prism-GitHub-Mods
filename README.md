# Prism GitHub Mods

Неофициальный патч для Prism Launcher 11.1.1. Добавляет вкладку **GitHub** в окно **Редактировать сборку → Моды → Скачать моды**.

Каталог `mods.json` содержит проверенные JAR из публичных GitHub Releases Detemkur Studios. Код патча находится в `patches/github-mods.patch`. Основа зафиксирована на [Prism Launcher 11.1.1](https://github.com/PrismLauncher/PrismLauncher/tree/7d2d3c1ec6fcf8255ebacd02d9f792688575dfb4).

## Установка

1. Открой Releases и скачай `Prism-GitHub-Mods-Setup-x64.exe` из релиза v0.1.0.
2. Выбери `prismlauncher.exe` и папку данных. Если используешь portable или отдельную папку через `--dir`, проверь, что установщик выбрал нужную папку с `prismlauncher.cfg`.
3. Нажми **Установить патч**, закрой обычный Prism и нажми **Открыть Prism**. При следующем запуске используй ярлык **Prism GitHub Mods**.
4. Открой сборку с Fabric → **Моды → Скачать моды → GitHub**. Выбери мод и релиз. Требуемые зависимости указаны в описании. Fabric API можно установить через прежние вкладки.

Сборка запускается из отдельной папки под `%LOCALAPPDATA%\Detemkur Studios\Prism GitHub Mods` с твоим существующим каталогом данных. Обычный Prism можно открыть прежним ярлыком. Закрой одну копию перед запуском другой.

Интерфейс использует программную отрисовку WPF. Пузырьки и звезду можно отключить. Кнопка **Выбрать музыку** открывает локальный аудиофайл. **Пауза** останавливает воспроизведение на текущей позиции, **Стоп** возвращает к началу. В поле рядом можно указать секунду, на которой звезда вспыхнет.

## Сборка

- GitHub Actions собирает пропатченный Prism из зафиксированного upstream-коммита.
- Установщик собирается из `installer` командой `go build -trimpath -ldflags="-s -w -H=windowsgui" -o Prism-GitHub-Mods-Setup-x64.exe .` в Windows x64. Для кросс-сборки установи `GOOS=windows`, `GOARCH=amd64`, `CGO_ENABLED=0`.
- `python3 tools/catalog.py` сверяет SHA-256 и метаданные JAR и обновляет каталог для перечисленных в скрипте проектов.
